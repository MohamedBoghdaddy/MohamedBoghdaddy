# Engineering Focus

## AI Systems Architecture

I design AI systems as production software rather than isolated model calls.

That includes:

```text
User Request
     ↓
API Gateway
     ↓
AI Orchestrator
     ↓
Context / Retrieval Layer
     ↓
Model Router
 ┌────┼────┐
 ↓    ↓    ↓
GPT Claude Gemini
 └────┼────┘
      ↓
Validation
      ↓
Caching
      ↓
Observability
      ↓
Structured Response
```

Key engineering concerns include:

- Provider fallback
- Model selection
- Token optimization
- Context management
- Prompt caching
- Response caching
- AI retries
- Rate limits
- Structured outputs
- Streaming
- Evaluation
- Cost tracking
- Reliability
- Hallucination reduction
